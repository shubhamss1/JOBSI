# JOBSI

A Next.js job portal connected to the public Blogger feed at https://jobsiind.blogspot.com.

## Run locally
1. Install Node.js (LTS) from https://nodejs.org if you want to run locally.
2. Run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

## Blogger connection
Published Blogger posts are fetched from the public Blogger JSON feed and cached for up to five minutes. New posts appear automatically after the cache refreshes.

For best results, add Blogger labels such as Banking, Government Jobs, Railway, IT & Tech, and Private Jobs.
